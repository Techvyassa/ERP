To run all queued jobs in Laravel, you have several options depending on your queue configuration:

1. For Development (QUEUE_CONNECTION=sync)
Jobs run immediately when dispatched - no need to run anything manually.

2. For Database Queue (QUEUE_CONNECTION=database)
Run the queue worker:

php artisan queue:work
Or run all pending jobs once:

php artisan queue:work --stop-when-empty
3. Run Specific Failed Jobs
View failed jobs:

php artisan queue:failed
Retry all failed jobs:

php artisan queue:retry all
Retry a specific failed job:

php artisan queue:retry {job-id}
4. For Your Specific Case (ProvisionTenantJob)
Since I changed the registration to run synchronously, you don't need to run jobs manually anymore. But if you have pending organizations that were created before the change, you can:

Option A: Create a command to provision pending organizations

5. Queue Worker Commands Summary
# Start queue worker (keeps running)
php artisan queue:work

# Process jobs until queue is empty
php artisan queue:work --stop-when-empty

# Process only 10 jobs then stop
php artisan queue:work --max-jobs=10

# Process jobs for 60 seconds then stop
php artisan queue:work --max-time=60

# Listen for new jobs (restarts worker on code changes)
php artisan queue:listen

# Clear all jobs from queue
php artisan queue:clear

# View failed jobs
php artisan queue:failed

# Retry all failed jobs
php artisan queue:retry all

# Flush all failed jobs
php artisan queue:flush
